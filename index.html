About

Welcome to ICICS 2027

The 29th International Conference on Information and Communications Security (ICICS 2027) will be held in Chengdu, China.

Established in 1997, ICICS is an annual international forum for researchers and practitioners to present and discuss advances in information and communications security. ICICS 2027 continues this tradition with a focused technical programme and peer-reviewed research contributions.

Hosted by University of Electronic Science and Technology of China

Call for Papers

Topics of Interest

Submissions are invited on all aspects of information and communications security. The preliminary scope, based on recent ICICS calls, includes but is not limited to:

  • Access control and authorization
  • Applied cryptography
  • Authentication and identity management
  • Blockchain and distributed-ledger security
  • Cloud and edge security
  • Cyber-physical systems security
  • Data and database security
  • Digital forensics
  • Embedded and IoT security
  • Hardware security
  • Information-flow security
  • Intrusion and anomaly detection
  • Malware analysis
  • Mobile and wireless security
  • Network security
  • Post-quantum security
  • Privacy-enhancing technologies
  • Protocol security
  • Secure software and systems
  • Security and privacy in AI
  • Security measurement and evaluation
  • Security of critical infrastructure
  • Usable security and privacy
  • Web and application security

For Authors

Submission Guide

Preliminary information. Final page limits, review rules and the submission link will be confirmed in the official ICICS 2027 call for papers.
  • Papers must be original, unpublished work and must not be under review elsewhere.
  • Submissions should be anonymous and prepared in English for double-blind review.
  • Authors should use the Springer LNCS proceedings template.
  • Recent ICICS editions allowed up to 18 pages including references, with appendices bringing the total to no more than 20 pages. The 2027 limit is subject to confirmation.
  • Accepted papers must be presented by at least one registered author.
